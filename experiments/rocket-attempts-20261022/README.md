# Rocket diagnostic attempts

These unsuccessful attempts are preserved to explain voltage sag, tracking and
start-state failures, telemetry loss, and the takeoff crash. They are not
successful mission records. Each subdirectory includes the complete compressed
raw telemetry, exact execution settings, summary, and checksums. Single-stage
records include target/model and mapped-reference data. Retarget attempts link
to the shared two-stage target plans in the full-reference retarget archive.

Original output folders remain unchanged and ignored. Timestamps in directory
names are UTC; see event timestamps and configuration files for each record.
